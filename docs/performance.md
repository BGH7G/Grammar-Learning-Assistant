## 优化点

- 对 DeepSeek 官方接口显式关闭默认思考；按需开启并选择强度。
- 原文在 Rust 无损切片；模型只生成结构、翻译和说明，减少输出 token 及对齐修复。
- 使用有效 JSON 示例，优先按短语分组，限制解释条数与长度。
- 校验失败反馈具体节点及范围错误，最多修复一次；保留每次请求统计。
