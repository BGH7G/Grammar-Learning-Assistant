# 第二阶段：先跑通触发与状态管理

> 历史记录：下述原型已于 2026-10-26 按用户要求移除，包括顶部面板、取词线程、旧 IPC 和系统复制操作。之后已接入新的通用剪贴板取词，见 [当前说明](clipboard-selection.md)。下文为旧实现及当时验证结果，不能作为当前功能说明。

实现日期：2026-10-26。本次覆盖路线的步骤 A/B/C，不代表整个第二阶段完成。

## 使用

1. 启动桌面应用，展开顶部“取词设置与触发记录”。默认注册 Ctrl+Alt+E；冲突时显示提示，可改为 Ctrl+Alt 加另一个字母。设置只在本次运行有效。
2. 手动开启“记事本复制原型”。原型初始关闭，快捷键仍可记录触发。
3. 使用空或标准纯文本剪贴板，在记事本选择连续文字，按快捷键并自然松开按键。
4. 取词结束并完成剪贴板收尾后显示现有窗口，预填原文。未提交输入存在时，需要点击“替换输入”；不会自动调用模型。

从 Chrome/Edge 或新版记事本复制得到的内容可能附带注册格式，不能据肉眼看到纯文本就认定剪贴板只有纯文本。原型遇到这些**原有格式**会拒绝自动复制；这是当前明确的边界。

## 触发与状态

- Rust 注册快捷键；Windows 插件自身使用 MOD_NOREPEAT，同时应用按按下/松开事件过滤重复。
- 回调先记录前台 HWND，再生成 captureId 与触发时间，只向单个有界工作线程投递。取词期间再次触发记为 busy，不替换正在执行的任务、不排队并发复制。
- 前端只接收可序列化状态。Rust 保留最近触发、成功结果、错误和修订号；事件只通知状态变化。前端先监听再查询，并在窗口获得焦点时补查，拒绝较旧修订的快照，按 captureId 去重预填。
- 采集和模型分析分开执行。接纳新取词时清除旧请求标识、会话指标及旧解析视图；有未提交文本则保留并提供替换入口。继续复用 prepare_analysis / expand_node。
- 请求在工作线程开始前超过 2 秒则丢弃。等待修饰键 800ms、观察复制 800ms；每次剪贴板锁重试最多 300ms。控件消息每次最多等 100ms。这些是单步骤预算，不是严格的整个事务硬超时。
- 退出请求发生于取词中时，停止接受新触发，等现有事务返回后退出；异常捕获也会清除 busy。

## 受控复制边界

- 仅接受顶层 Notepad 窗口及 Edit / RichEditD2DPT 焦点控件；浏览器、Word、PDF、其他编辑器及受保护控件不自动复制。
- 用 EM_GETSEL 确认非空选区，并在限定文档大小内通过有超时的 WM_GETTEXT 校验准确文字；复制前后检查窗口、焦点、范围与内容。选区最多 2,000 Unicode 字符；原型检查文档最多 200,000 UTF-16 单元。
- 初始剪贴板只备份空、CF_TEXT、CF_OEMTEXT、CF_UNICODETEXT、CF_LOCALE；每个格式最多 1MiB。富文本、图片、文件列表及注册格式不触碰。
- 注入前自然等待修饰键释放，不伪造用户松键；核对 SendInput 实际注入数量，部分注入时仅尝试清理本次注入按键。
- 剪贴板序列号必须变化，所有者进程必须属于目标，Unicode 文本必须与已确认选区完全一致；否则返回错误，绝不采用旧剪贴板。
- 本次目标复制产生的富文本伴随格式不需要备份；只记录其格式标识与 Unicode 文本以复查。恢复的是操作前支持范围内的快照，未承诺恢复原本的富文本。
- 使用工作线程上的隐藏 message-only owner 窗口；锁和全局内存使用 RAII。恢复时在同一次 OpenClipboard 内复核序列号、格式和 Unicode 内容；出现外部变化则跳过恢复。全部分配成功后才 EmptyClipboard，SetClipboardData 成功后转移所有权。
- 恢复失败会提示。跨进程竞态和晚到写入仍有边界；系统剪贴板历史与第三方管理器中的临时记录不能撤销。不默认提权。

## 已验证

真实桌面验证使用 computer-use 技能与独立的公开测试标签页，没有修改用户原有文件、保存模型设置或调用模型。

| 场景 | 结果 |
| --- | --- |
| 新版记事本选中 The cat sleeps.，已知纯文本基线 | 快捷键触发成功，15 字符准确预填；两次成功样例均显示 27ms。仅为本机样例。 |
| 取词后将剪贴板粘回测试输入框 | 得到 Clipboard baseline.，确认恢复原基线。 |
| 有未提交输入时再次取词 | 保留原输入，显示选区预览及“替换输入 / 保留当前输入”；点击替换后预填成功。 |
| 记事本没有选区 | 返回 no_selection，原输入不变，不误用旧剪贴板。 |
| 操作前剪贴板含 Chromium 注册格式 | 返回 unsafe_clipboard，未执行复制。 |
| 状态单元测试中连续触发十次 | 全部 busy，原任务 ID 不变；过期完成不能结束当前任务，失败完成后可以再次触发。 |

真实按住修饰键、注入中切窗、热键占用、用户在复制过程中再次复制、窗口退出中事务、高权限窗口以及每应用 20 次兼容性回归，尚未完成桌面实测。不能据上述样例宣称全部验收通过。

## 测试辅助

默认 cargo test 不触碰系统剪贴板。两个 ignored 的本地诊断用例均不调用模型：inspect_clipboard_formats 仅读取格式名称；prepare_plain_text_baseline 仅在当前 Unicode 文本准确等于公开测试基线 Clipboard baseline. 时才把该测试剪贴板改为纯文本。后者用于排除浏览器附加格式，不用于产品功能，也不应在正常使用中运行。
