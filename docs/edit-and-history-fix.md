# 原位编辑与重复分析复用

- 点击编辑原文，直接在原来的原文区域使用文本输入，不跳转、不隐藏译文或抽屉，不新增取消按钮。
- 结果视图始终挂载，保留当前会话、译文、已加载结构、选中句子及抽屉。编辑按钮可再次聚焦原文。
- 编辑不发起分析请求。修改后提示下方仍为修改前结果；点击重新分析才提交。空输入或超过 2,000 字符禁用提交。
- 原文未修改或已恢复原文本时，点击重新分析直接恢复可点击句子，不调用后端或模型，保留当前抽屉。
- 其他历史输入由后端比较原文（含空白）、自动分句开关和模型配置指纹，返回原会话全部已加载层。未加载层仍按需请求。
- 当前为本次运行最近 8 个会话缓存；命中提升保留顺序。退出后不保留；保存模型配置会清空缓存。没有新增原文落盘。
- 新解析失败保留原解析与编辑文本，不清空结果。

验证：生产构建、队列回归通过。历史缓存后端的 34 项测试和 Clippy 在上一轮通过，本轮未修改后端。
浏览器离线实测：选句 2 → 原位编辑 → 修改 → 恢复原文 → 重新分析，全程保留句 2 抽屉；编辑前后阅读区和抽屉边界尺寸完全一致（1280×720）。
