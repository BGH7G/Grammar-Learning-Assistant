# 句子分析界面：前端效果图版本

本版替换之前的左右解释面板方案。原始基线仍位于 ui-backups/sentence-analysis-20261025-112957/。

布局：原文摘要及句数/字符数、编辑原文、重新分析 → 多句标签（有多句时）→ 分层解析卡片（全句/主干切换、带角色标签的完整彩色原句、整句翻译）→ 所选成分详情卡片（面包屑、作用、译文、内部结构色块）→ 折叠性能及说明。

完整原句始终显示当前句子的首层结构，点击色块选中并按需加载内部结构；连续下钻只更新下方详情。←/→ 切换同级，Enter 在详情区域焦点上继续进入可展开子项，Esc 返回上一级；按钮本身仍支持原生键盘激活。最多四层，已加载结构不重复请求。

作用文案为基于角色的通用语法说明，不是模型返回的逐句解释；未提供单独译文的终端成分明确提示参考整句翻译。模型返回的 notes 仍作为当前片段说明，不猜测节点绑定。不根据 Well 等词面强行改写模型分类，本轮未变更后端协议。主干模式为当前首层角色驱动的淡化阅读辅助。

验证：TypeScript/Vite 构建；浏览器离线示例点击主语→关系从句→内部结构，完整原句保持显示，面包屑关联当前路径。没有新增真实模型测试请求。
